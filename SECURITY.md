# Security policy

## Reporting a vulnerability
Email **gabejar@usa.com** with details and a proof of concept if available.
Please do not open a public issue for security reports. Expect an
acknowledgement within 72 hours.

## Scope
See [`THREAT_MODEL.md`](THREAT_MODEL.md) for trust boundaries and the things this
project explicitly does not defend against.

## Supported versions
The latest released minor version receives security fixes.
